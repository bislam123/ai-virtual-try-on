# AI Try-On — frontend

Mobile-first React + TypeScript + Tailwind CSS PWA. Talks to the FastAPI backend in `../backend/`.

See [../docs/DEVELOPMENT.md](../docs/DEVELOPMENT.md#milestone-4--mobile-first-web-ui) for setup, run, and test instructions, and [../docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md) for how this fits into the rest of the system.

```bash
npm install
npm run dev      # requires the backend running — see docs/DEVELOPMENT.md
npm run build
npm run lint
```
