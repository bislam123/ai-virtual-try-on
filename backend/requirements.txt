# Installed into the same venv as ai/ (ai/.venv) — this backend calls the AI
# pipeline in-process, so it needs everything ai/ needs (torch, fashn-vton,
# aitryon-bodyparser) plus the web-framework packages below. See
# docs/DEVELOPMENT.md for why they currently share one environment, and when
# that would need to split (e.g. backend and AI inference on different hosts).
#
# Pinned to exact versions (not floor-only >=), deliberately: this project
# has no lockfile/pip-compile tooling anywhere else, and adding one just for
# this would be new tooling for a handful of packages — pinning the direct
# dependencies themselves is the smallest change that makes `pip install -r
# requirements.txt` reproducible instead of resolving to whatever's newest
# on install day. Every version below is exactly what's installed in
# ai/.venv and passing the full test suite as of 2026-09-19. Bump
# deliberately (not via a blanket `pip install -U`), one at a time, and
# re-run the full backend suite (`pytest`) before committing a bump.
